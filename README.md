# AURVM – Luxury Watch Website

A premium luxury watch brand website inspired by haute horlogerie and modern luxury design.

## Features

* Responsive Design
* Dark / Light Theme
* Custom SVG Watch Illustrations
* Interactive Watch Showcase
* Luxury Brand Story Section
* Ambassador Section
* News & Editorial Section
* Smooth UI Animations
* Mobile Navigation

## Technologies Used

* HTML5
* CSS3
* JavaScript (Vanilla JS)
* SVG Graphics
